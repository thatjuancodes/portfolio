# ThatJuanCodes Portfolio

A modern, responsive portfolio website built with React, TypeScript, and Chakra UI v3. This project showcases recent development projects and serves as a demonstration of modern web development practices.

## 🚀 Features

- **Modern Stack**: Built with React 18, TypeScript, and Vite for fast development and optimal performance
- **Beautiful UI**: Styled with Chakra UI v3 for a clean, professional design
- **Responsive Design**: Mobile-first approach ensuring great experience across all devices
- **Theme System**: Custom theme with light/dark mode support
- **Type Safety**: Full TypeScript integration for better development experience
- **Fast Build**: Powered by Vite for lightning-fast hot module replacement

## 🛠️ Tech Stack

- **Frontend**: React 18, TypeScript
- **Styling**: Chakra UI v3, Emotion
- **Build Tool**: Vite
- **Package Manager**: Yarn
- **Animation**: Framer Motion (via Chakra UI)

## 📦 Getting Started

### Prerequisites

- Node.js (v18 or higher)
- Yarn package manager

### Installation

1. Clone the repository:
```bash
git clone <repository-url>
cd thatjuancodes
```

2. Install dependencies:
```bash
yarn install
```

3. Start the development server:
```bash
yarn dev
```

4. Open your browser and navigate to `http://localhost:5173`

## 🏗️ Available Scripts

- `yarn dev` - Start the development server
- `yarn build` - Build the project for production
- `yarn preview` - Preview the production build locally
- `yarn lint` - Run ESLint to check code quality

## 🚀 Deployment

The project can be deployed to any static hosting service:

1. Build the project:
```bash
yarn build
```

2. Deploy the `dist` folder to your hosting service of choice (Vercel, Netlify, GitHub Pages, etc.)
